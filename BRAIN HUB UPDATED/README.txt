BRAIN HUB — INTEGRATED WEBSITE

This folder combines your original Brain Hub website with the 50-question Quiz Battle.

FILES
- index.html: Home page
- about.html: About Brain Hub
- services.html: Activities and direct Quiz Battle link
- quiz.html: Interactive 50-question Quiz Battle
- blog.html: Blog page
- contact.html: Contact page
- style.css: Original Brain Hub styling
- quiz.css: Quiz Battle styling
- script.js: Quiz Battle logic and 50 questions

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server.
4. Use the navigation menu or Services page to open Quiz Battle.

NOTES
- Your original pages and original style.css are preserved.
- The quiz is a client-side demo. Scores are calculated in the browser; online shared leaderboards would require a backend/database.
- The contact form is preserved as supplied; it does not send messages unless connected to a form service/backend.
